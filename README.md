# 3D-PER

Assets 3D (personnages, coiffures et bibliothèques d'animations) par [@Quaternius](https://quaternius.com), versions Standard.

## Contenu

| Dossier | Description |
| --- | --- |
| `Universal Base Characters[Standard]` | Personnages de base + coiffures (FBX, glTF/GLB, textures PNG) |
| `Universal Animation Library[Standard]` | Bibliothèque d'animations 1 — Unity (FBX) et Unreal/Godot (GLB) |
| `Universal Animation Library 2[Standard]` | Bibliothèque d'animations 2 + mannequin féminin |

Chaque bibliothèque d'animations existe en deux variantes : le fichier suffixé `_RM` a le *root motion* baké dans chaque animation, l'autre non.

Les images `Unity_Setup.png`, `Unreal_Setup.png` et `Godot_Setup.png` documentent les réglages d'import pour chaque moteur.
